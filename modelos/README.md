# Formatos de registro

São modelos vazios, sem respostas esperadas. O agente deve produzir as saídas somente após receber a pergunta e consultar as fontes. O retorno humano só existe quando efetivamente fornecido pelo usuário.

- [EVIDENCIAS.md](EVIDENCIAS.md): passagens e achados.
- [REVISAO.md](REVISAO.md): suporte e alterações sem apagar a primeira versão.
- [RETORNO_HUMANO.md](RETORNO_HUMANO.md): registro posterior, nunca gabarito antecipado.
# Contrato de achados

[ACHADOS.schema.json](ACHADOS.schema.json) define os conjuntos versionados produzidos pelo fluxo. Consulte [o guia](../docs/ACHADOS_IA.md) e [o exemplo sintético](../testes/fixtures/achados_exemplo.json). O exemplo não é corpus de apuração nem arquivo pronto para registro em uma rodada real.
