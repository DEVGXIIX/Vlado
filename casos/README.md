# Casos de apuração

Cada subpasta é uma apuração distinta. O catálogo contém apenas metadados de escolha; o agente não deve ler documentos de casos inativos para procurar pistas.

O projeto começa sem caso selecionado. Para uma nova pauta, receber os arquivos, cadastrar um ID com `scripts/criar_caso.py` e selecionar o caso solicitado com `scripts/selecionar_caso.py`. Depois registrar o inventário e aguardar a pergunta. IDs documentais como D001 podem se repetir em casos diferentes: citar sempre o caso junto da referência quando houver risco de ambiguidade.

Não guardar gabaritos ou avaliação preenchida nestas pastas. Para comparar documentos de duas pautas, criar explicitamente um corpus de seleção conjunta e preservar os identificadores de procedência, sem modificar os casos de origem.
